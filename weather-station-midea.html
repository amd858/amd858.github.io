Weather Station Midea

Smart AC climate control · reverse-engineered IR protocol · dual-sensor monitoring

An intelligent climate control system that autonomously manages heating, cooling, and humidity via reverse-engineered Midea IR protocol. Combines environmental monitoring (temperature, humidity, heat index) with sophisticated state machines, DIP switch calibration, and real-time LCD feedback. Supports Arduino, ESP32, STM32, and RP2040 platforms.

Project Purpose

This system implements autonomous climate management for residential or commercial spaces by:

  • Monitoring conditions via dual-sensor approach (DHT11/22 + HDC1080 option)
  • Controlling Midea AC units using decoded 48-bit IR protocol (Pronto format)
  • Maintaining comfort zones with threshold-based automation (heating, cooling, humidification)
  • Providing calibration via hardware DIP switches (±0.5–3.5°C offset adjustment)
  • Displaying status on 16×4 LCD (real-time temp, humidity, mode, AC state)
  • Handling failures gracefully with debouncing, bounce detection, and fallback logic

Midea IR Protocol

48-Bit Command Structure

Bits 0–3:   Power (0=OFF, 1=ON)
Bits 4–7:   Mode (0=Cool, 1=Dry, 2=Fan, 3=Heat)
Bits 8–13:  Temperature (6 bits, range 16–31°C)
Bits 14–16: Fan Speed (0=Auto, 1=Low, 2=Mid, 3=High)
Bits 17–20: Swing (0=OFF, 1=ON) — vertical louver auto-swing
Bits 21–23: Reserved (zero padding)

Pronto Format

Format
Hexadecimal; two-part IR commands (Part A + Part B)
Part A
100–114 phase units (38 kHz carrier frequency encoding)
Part B
50 phase units (command tail)
Buffer Size
270 bytes per Pronto code; stored in PROGMEM to save RAM
Transmission

Auto-Repeat Logic

When AC or heater is in active (ON) state, the system re-transmits commands every 10 minutes (600,000 ms) to compensate for IR signal degradation or receiver interference. This ensures reliable continuous operation even if a single transmission packet is lost.

Sensor Data Flow

Reading Sequence (Main Loop)

  1. Read DHT11/22 (wait ≥2 seconds between reads)
  2. Read HDC1080 (I²C, if present)
  3. Calculate heat index from temp + humidity
  4. Compare against thresholds
  5. Execute AC, heater, humidifier state machines
  6. Transmit IR command (if state changed)
  7. Update LCD with current status
  8. Check button inputs and DIP switch calibration
  9. Sleep/delay until next cycle

Error Handling

  • Sensor Failure: Caches last valid reading; retries on next cycle
  • IR Transmission Fault: Retries up to 3 times before alerting user
  • AC Non-Response: Logs failed command; suggests manual intervention
  • Button Glitch: Software debouncing with configurable thresholds prevents false triggers

Deployment & Installation

Hardware Assembly

  1. Mount ESP32 on breadboard or PCB
  2. Connect DHT11/22 to GPIO 15 with 4.7 kΩ pull-up
  3. Connect HDC1080 (optional) to I²C bus (SCL/SDA)
  4. Build IR transmitter circuit: IR LED + 2N2222 transistor (base to GPIO 4 via 470 Ω)
  5. Wire 555 timer signal conditioning circuit for IR receiver (GPIO 15)
  6. Connect LCD via I²C (address 0x27)
  7. Wire DIP switches to GPIO 9–12 (with pull-ups)
  8. Connect mode toggle to GPIO 8 and AC disable button to GPIO 7
  9. Power via 5V/1A USB or barrel jack (9V with regulator)

Firmware Upload

  1. Install Arduino IDE 1.8.x or later
  2. Install ESP32 board package via Boards Manager
  3. Install required libraries: IRremote, DHTesp, LiquidCrystal_I2C, ClosedCube_HDC1080
  4. Open midea_ac.ino in Arduino IDE
  5. Select board type: "ESP32 Dev Module" (or appropriate variant)
  6. Configure serial port and upload

Calibration Steps

  1. Power on; verify LCD displays temperature and humidity
  2. Compare DHT reading against reference thermometer
  3. If DHT reads high/low, adjust DIP switches to match (±0.5–3.5°C range)
  4. Point IR LED at AC unit and press mode button; verify AC responds
  5. Test temperature setpoints: adjust min_temp/max_temp in code as needed
  6. Verify humidifier threshold behavior (activate at 39%, deactivate at 43%)

Testing Checklist

  • ☐ DHT sensor reads temperature & humidity (±2°C accuracy)
  • ☐ HDC1080 (if present) reads with expected ±0.2°C precision
  • ☐ LCD displays temp, humidity, mode, AC state, heat index in real-time
  • ☐ DIP switches adjust temperature offset correctly (±0.5–3.5°C)
  • ☐ Mode toggle (pin 8) switches between heating and cooling operation
  • ☐ AC disable button (pin 7) toggles AC enable/disable state
  • ☐ IR LED transmits; AC unit responds to Cool/Heat/Fan commands
  • ☐ AC activates when heat index > 27.2°C AND humidity > 33%
  • ☐ AC deactivates when heat index < 26.8°C OR humidity < 30%
  • ☐ Heater activates when temp < 19.8°C; deactivates when > 20.2°C
  • ☐ Humidifier activates at <39% humidity; deactivates at >43%
  • ☐ State machine bounce detection prevents rapid on/off cycling (6-cycle debounce)
  • ☐ Auto-repeat logic re-transmits commands every 10 minutes when AC/heater active
  • ☐ Button debouncing works; no chattering or false triggers
  • ☐ Power consumption measured; within 80–150 mA typical range
  • ☐ No memory leaks over 1+ hour runtime; stable operation
